# 06 - Diagramas UML

## 6.1 Situação nesta versão

**Nenhum novo diagrama UML foi produzido ou selecionado nesta versão.** A instrução de levantamento determina que os tipos de diagrama sejam escolhidos pela pessoa que executa o processo; como essa escolha não foi recebida, a equipe não deve selecionar diagramas por conta própria.

A seção ficará pendente até que a pessoa responsável indique explicitamente os tipos que deseja incluir. Depois da escolha, cada diagrama deverá conter: nome, finalidade, elementos principais, requisitos relacionados, representação visual no PDF e código-fonte editável no Markdown em notação/ferramenta identificada.

## 6.3 Registro de seleção pendente

| Campo | Situação |
|---|---|
| Tipos UML escolhidos | Pendente de indicação expressa |
| Responsável pela escolha | Pessoa solicitante / cliente |
| Ferramenta ou notação | A definir após a escolha (ex.: PlantUML, Mermaid ou ferramenta UML compatível) |
| Diagramas renderizados no PDF | Nenhum nesta versão |
| Código-fonte editável | Nenhum nesta versão |
| Requisitos relacionados | A mapear depois da escolha |

## 6.4 Critério para atualização

Quando os tipos forem escolhidos, atualizar esta seção e a matriz de rastreabilidade; produzir o fonte editável; revisar consistência com RF/RNF/regras; renderizar cada diagrama; inserir as imagens no PDF; e verificar se os diagramas não introduzem decisões não aprovadas.
