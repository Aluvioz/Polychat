## Como interpretar esta versão

- **Confirmado:** informação declarada no levantamento.
- **Derivado:** detalhamento necessário para tornar uma informação verificável; requer validação quando indicado.
- **Proposta para MVP:** organização recomendada do primeiro incremento, não aprovada ainda.
- **Recomendação:** controle sugerido pela equipe para discussão, não aprovado pelo cliente.
- **Pendente:** informação ainda não fornecida ou decisão ainda não tomada.

Identificadores OBJ, RF, RNF, RN e CA são únicos nesta linha de base e devem ser preservados em revisões posteriores. Não reutilize identificadores removidos.

## Situação de aprovação

A versão 0.2 não é uma aprovação do cliente. A identificação do representante da FORD e do PO, as respostas às questões críticas, a validação técnica/QA e a revisão por PR ainda são necessárias para fechar a baseline.

## Aviso sobre diagramas

A documentação não cria nem seleciona diagramas UML nesta versão, pois a escolha dos tipos permanece pendente. A seção 06 registra arquivos preexistentes em docs/, sem declará-los aprovados ou atualizados.
